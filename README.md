# 🏏 IPL Analysis Dashboard - Power BI


An interactive and insightful Power BI dashboard analyzing Indian Premier League (IPL) matches, teams, and players. This project aims to extract meaningful patterns and performance metrics from IPL data to support better understanding of cricket analytics.

---

## 📊 Project Overview

The **IPL Analysis Dashboard** is built using Microsoft Power BI and provides a deep dive into IPL statistics including:

- Match outcomes
- Team-wise performance
- Player statistics
- Season trends
- Venue impact

---

## 🚀 Features

✅ Overall match and season summaries  
✅ Top-performing teams and players (by runs and wickets)  
✅ Venue-wise winning trends  
✅ Toss vs Match Outcome correlation  
✅ Filters for Team, Venue, Season, and Match Result  
✅ Clean, interactive Power BI visuals


---

## 📁 File

- `IPL_Analysis.pbix`: Main Power BI report file containing all dashboards and visuals

---

## 📥 How to Use

1. Download or clone this repository.
2. Open the `.pbix` file using **Microsoft Power BI Desktop**.
3. Explore and interact with the visuals and filters.

> 📌 If you don't have Power BI Desktop, you can [download it here](https://powerbi.microsoft.com/desktop/).

---

## 🧠 Insights Extracted

- How toss affects match outcomes
- Most successful franchises over the years
- Players with consistent high run/wicket performance
- Match-winning venues for specific teams

---

## 📌 Tools Used

- **Power BI Desktop** – for building the report
- **IPL Dataset** (Kaggle or official sources)
